# Checklists reutilizáveis

Os checklists deste diretório são modelos genéricos para projetos futuros. Uma caixa desmarcada não representa pendência deste projeto e uma atividade listada não representa que ela foi executada.

As atividades comprovadamente realizadas estão descritas em [requisitos e escopo](../docs/03-requisitos-e-escopo.md) e [testes e validações](../docs/10-testes-e-validacoes.md).
